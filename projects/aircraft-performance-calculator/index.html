Overview

The idea

A browser-based calculator for the numbers that decide what an aircraft can do. Adjust wing area, lift and drag coefficients, airspeed, altitude, weights, thrust and fuel burn, and every result updates as you drag.

Air density isn't a fixed input: it comes from an International Standard Atmosphere model implemented from scratch, so climbing to altitude changes lift, drag and dynamic pressure the way it would on a real aircraft.

Features

What it does

  • Lift and dragComputed from the standard aerodynamic force equations.
  • L/D ratioAerodynamic efficiency, a core figure in aircraft design.
  • Thrust-to-weightDecides climb and manoeuvre capability.
  • Breguet rangeThe equation aerospace engineers use to estimate how far an aircraft can fly.
  • ISA atmosphereAir density updates automatically with altitude.
  • Dynamic pressureFrom airspeed and density at altitude.
  • Live statusFlags like "below weight", "excellent" L/D and "long-haul" range.
  • Ten inputsWing area, CL, CD, airspeed, altitude, gross weight, thrust, TSFC, fuel and empty weight.

Under the hood

The maths

LiftL = ½ · ρ · V² · S · CL
DragD = ½ · ρ · V² · S · CD
L/D ratioη = CL / CD
Thrust / weightτ = T / (W · g)
Breguet rangeR = (V / c) · (L/D) · ln(Wi / Wf)
ISA densityρ(h) = 1.225 · e−h/8500
